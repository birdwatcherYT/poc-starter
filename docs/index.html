Create Document Endpoint

Request Body schema: application/json
required
title
required
string (Title) [ 1 .. 200 ] characters

content
required
string (Content) [ 1 .. 5000 ] characters

本文。これとタイトルを連結したものから埋め込みを作る（今はダミー）
